# VIBEDECK — пять направлений

Пять самостоятельных дизайн-вариантов главной страницы. Продукт, данные и
механика одни и те же; визуальный мир у каждого свой.

## Как смотреть

Из корня проекта:

```
python -m http.server 5173
```

- `http://localhost:5173/variants/` — сводный лист со всеми пятью;
- `http://localhost:5173/variants/01-riso/` … `/05-atelier/` — отдельные миры.

Направление 02-swiss перенесено в корень как основная страница; сам вариант
синхронизирован с ней. Остальные четыре остаются архивом.

## Состав

```
variants/
  core.js          данные, случайный выбор, localStorage, копирование HEX, анонс
  index.html       сводный лист (не часть продукта)
  01-riso/         ризограф: два цвета, неприводка, перепечатка
  02-swiss/        макет: белое поле, строки-регистры, один красный сигнал
  03-solari/       табло: лепестки, янтарь, механический перебор
  04-y2k/          личная страница 2000: звёзды, хром, бегущая строка
  05-atelier/      ателье: тёмный кабинет, серифный герой, образцы ткани
  fonts/           self-hosted WOFF2 + @font-face
  preview/         снимки 1440×900 из этих же файлов
```

Каждый вариант — `index.html + style.css + page.js`. Общее: `core.js`
(`window.Vibedeck`), ключ хранения `vibedeck:last`, данные
`data/vibedeck.json`. Слоты, порядок и типы берутся из JSON; новый слот или
тип рендера не требует переписывать прокрут.

## Шрифты

Все — с Google Fonts, лицензия SIL Open Font License 1.1, файлы лежат рядом
(`*.woff2`, latin + cyrillic, где поддерживается):

| Семейство | Где | Что взято |
|---|---|---|
| Unbounded 400–900 | 01 | кириллица + латиница |
| Inter Tight 300–800 | 02, 05 | кириллица + латиница |
| Roboto Condensed 300–700 | 03 | кириллица + латиница |
| Playfair Display 400–900 + italic | 05 | кириллица + латиница |
| Michroma 400 | 04 | только латиница (заголовок) |

## Предпросмотры

`preview/*.png` сняты из этих же файлов в headless Chrome при 1440×900, без
ретуши: остальные — 18.11.2026, `02-swiss` переснят 21.11.2026 после переноса
в корень. Снимки архивных вариантов показывают прежний набор настроений;
актуальная комбинация восстанавливается из общего ключа `vibedeck:last`.
