# VIBEDECK — Creative Idea Generator

Одностраничный инструмент для дизайнеров: выдаёт случайную комбинацию «ниша + настроение + название бренда + палитра» и служит стартовой точкой для нового концепта.

## Что делает

Один экран, четыре слота, одна кнопка `Крутить`. Все слоты крутят одновременно; после остановки на экране остаётся готовая комбинация. При следующем заходе показывается последняя прокрученная — без пустого экрана и без повторного запроса.

| Слот | Содержимое |
|---|---|
| `01 / Niche` | Категория бизнеса + конкретная ниша (Еда и напитки → газированные напитки, кофейня; Мода, Красота, Технологии, Лайфстайл, Гостеприимство, Спорт, Косметика, Дом и интерьер, Искусство и культура) |
| `02 / Mood` | Настроение: Спокойствие, Ностальгия, Дерзость, Уют, Мечтательность, Энергия, Меланхолия, Тепло, Лёгкость, Собранность, Игра, Таинственность |
| `03 / Name` | Короткое имя бренда: латиница, кириллица и единичные варианты с цифрами (VESNA, KEDR, ВОЛНА, ЗАРЯ, ДОМ 7, КАДР 2, ТОН 9) |
| `04 / Colors` | Палитра из 2–6 цветов: HEX, название цвета, образец + имя палитры (Terracotta & Cobalt) |

## Экран

- Верх — тонкая чёрная линейка, строка `VIBEDECK / инструмент` и крупный заголовок «Комбинация для нового концепта». Счётчика комбинаций, вводного абзаца и подсказок внизу нет.
- Четыре слота — горизонтальные строки-регистры: номер и название слота слева, крупное значение в центре, служебная подпись справа. Палитра — ряд цветных плашек с именем и HEX под ними.
- Кнопка `Крутить` — единственный элемент управления, стоит справа под строками, за горизонтальной линейкой.
- На планшете строки сжимаются, на телефоне перестраиваются в один столбец; кнопка занимает всю ширину и закреплена внизу.

## Механика прокрута

- Однократное нажатие запускает все четыре слота сразу.
- Значения сменяются серией мгновенных срезов; слоты останавливаются по очереди на 0.52, 0.7, 0.88 и 1.06 с.
- В момент остановки на верхней линейке строки срабатывает короткий красный тик, значение раскрывается шторкой.
- Новое значение не повторяет текущее, если в наборе есть другие варианты.
- Пока идёт прокрут, кнопка неактивна. Комбинация считается готовой после остановки последнего слота.
- Повторное нажатие после остановки — это новый прокрут с новым набором значений.

## Загрузка страницы

- При открытии показывается последняя прокрученная комбинация — состояние восстанавливается автоматически.
- Если сохранённого состояния нет или оно невалидно (например, изменился набор данных), показывается первая случайная комбинация без анимации.
- Пользовательских сохранений нет: ни избранного, ни истории, ни кнопки «Сохранить». Хранится только последняя комбинация — служебное состояние, а не пользовательская коллекция.

## Язык

- Интерфейс — по-русски: подписи, кнопка `Крутить`, подсказки, тосты, пустые состояния.
- По-русски также ниши, категории и настроения; имена брендов — микс латиницы и кириллицы, единичные с цифрами.
- По-английски остаются только названия слотов `Niche / Mood / Name / Colors`, имена палитр и цветов, HEX-коды.

## Данные и расширяемость

- Все варианты — в одном файле `data/vibedeck.json`; данные не хардкодятся в разметке.
- Структура: `{ version, slots: [ { id, label, type, items } ] }`.
  - `type: "list"` — элемент `{ title, meta? }` (`meta` — категория, например `Food & Beverage`).
  - `type: "palette"` — элемент `{ title, colors: [ { hex, name } ] }`, от 2 до 6 цветов.
- Порядок слотов в файле = порядок на экране; номер `01…04` выводится из порядка.
- Новый слот — это ещё один объект в `slots`; новый тип рендера добавляется в реестр «слот → рендер», без переписывания прокрута.

## Страницы и файлы

- `index.html` — главная: дизайн направления 02-swiss (строки-регистры, один красный акцент), без вводного блока и счётчика.
- `editor.html` — редактор данных (отдельная страница), использует общий `css/base.css`.
- `data/vibedeck.json` — 4 слота, 40 ниш, 12 настроений, 24 названия, 16 палитр.
- `css/deck.css` — самодостаточная вёрстка главной; `css/base.css` — токены, типографика и контролы редактора; `css/editor.css` — вёрстка редактора.
- `js/deck.js` — прокрут главной, восстановление последней комбинации, копирование HEX; `js/editor.js` — загрузка, правка, валидация, сохранение.
- `fonts/inter-tight-*.woff2` — шрифт главной; `fonts/oswald-*.woff2` остаются от прежней версии.
- `variants/` — галерея пяти дизайн-направлений; `variants/02-swiss/` синхронизирован с главной, остальные варианты — архив.
- `references/vide-deck-reference.jpg` — референс интерфейса от заказчика.

## Редактор данных

- Слева — список слотов с количеством элементов; справа — редактор выбранного слота.
- Правка названия, типа, значений, категорий; для палитр — название палитры, HEX и название каждого цвета.
- Перестановка и удаление элементов, добавление и удаление слотов и цветов (2–6 на палитру).
- Живая валидация: пустые значения, дубли, неверный HEX, количество цветов, минимум два элемента на слот.
- `Сохранить в файл` пишет JSON на диск через File System Access API; без поддержки — `Скачать JSON`. `Ctrl+S` = сохранить.
- Правки живут в памяти страницы: чтобы они попали в `data/vibedeck.json`, файл нужно сохранить.

## Запуск

- Нужен локальный сервер, потому что данные читаются `fetch`-ем:
  `python -m http.server 5173` из корня проекта, затем `http://localhost:5173/`.
- Редактор: `http://localhost:5173/editor.html`.
- Если открыть файл напрямую (`file://`), главная покажет инструкцию запуска, а редактор предложит выбрать JSON вручную.

## Копирование

- Клик по цветовой плашке копирует HEX этого цвета; лёгкий тост подтверждает копирование.
- Отдельной кнопки копирования нет — цвет и есть элемент взаимодействия.

## Визуальное направление

Швейцарский макет — Neue Grafik.

- Белый лист, чёрный текст, волосяные линейки; красный — единственный акцент (марка, тик посадки, кнопка).
- Крупная сжатая типографика Inter Tight, значения набраны в масштабе заголовка; служебные подписи — мелкий моноширинный капс.
- Сетка из двенадцати колонок, строки-регистры, много воздуха.
- Микроанимации сдержанные: мгновенные срезы, красный тик, шторка значения, тост копирования.
- Никаких SaaS-админок, стоковых иллюстраций, градиентных «AI»-клише.

## Стек

- Чистый HTML + CSS, без фреймворков, сборщиков и зависимостей.
- JavaScript — только там, где без него не работает механика (прокрут, чтение JSON, последняя комбинация, копирование); никакого React/Vite.
- Tailwind не используется: стили пишутся вручную в CSS.

## Инструменты

- Скилл `impeccable` установлен локально: `.opencode/skills/impeccable/`, команда `.opencode/commands/impeccable.md`.
- `/impeccable init` → `PRODUCT.md`, `/impeccable document` → `DESIGN.md`; дальнейшие правки UI идут через команды скилла (`shape`, `critique`, `polish`, `audit`, `animate`).

## Статус

Данные и редактор готовы (`data/vibedeck.json`, `editor.html`). Главная `index.html` переведена на направление 02-swiss: строки-регистры, быстрые срезы с красным тиком, восстановление последней комбинации, копирование HEX, адаптив строка / сжатая строка / столбец. Слот `Mood` наполнен настроениями, а не визуальными стилями.
