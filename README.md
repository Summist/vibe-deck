# VIBEDECK

Одностраничный генератор концептов: случайная комбинация ниши, настроения,
имени бренда и палитры — отправная точка для нового проекта. Один жест
`Крутить`, четыре независимых слота, без библиотек и сборки.

**Живая версия:** https://summist.github.io/vibe-deck/

## Локальный запуск

Данные читаются `fetch`-ом, поэтому нужен локальный сервер:

```
python -m http.server 5173
```

- главная — http://localhost:5173/
- редактор данных — http://localhost:5173/editor.html
- галерея направлений — http://localhost:5173/variants/

## Состав

```
index.html          главная
editor.html         редактор data/vibedeck.json
css/deck.css        вёрстка главной
css/base.css        токены и контролы редактора
css/editor.css      вёрстка редактора
js/deck.js          прокрут, восстановление комбинации, копирование HEX
js/editor.js        загрузка, правка, валидация, сохранение
data/vibedeck.json  4 слота: 40 ниш, 12 настроений, 24 имени, 16 палитр
fonts/              self-hosted WOFF2
variants/           пять дизайн-направлений и превью
```

## Документы

- `PRODUCT.md` — продукт и аудитория.
- `AGENT.md` — спецификация интерфейса, механики и файлов.
- `DESIGN.md` — дизайн-система (главная на момент 02-swiss описана в AGENT.md).

## Технологии

Чистый HTML + CSS + JavaScript. Без фреймворков, сборщиков и зависимостей.
Публикуется через GitHub Pages: workflow `.github/workflows/pages.yml`
собирает корень ветки `main` и выкладывает артефакт.
